## Практика в GigaBlocks вместе с преподавателем

**[Инструкция и файлы для самостоятельной сборки](https://alekstravin.github.io/genai-business-hse-2026/practice/)**

- [PDF-инструкция по сборке агента](practice/guide.pdf).
- [Весь комплект одним ZIP](practice/sever-kit.zip).
- [Готовый граф для резервного импорта](practice/ready-agent.json). После импорта нужно выбрать свой тенант в GigaRAG.
- Три документа для RAG и системная инструкция доступны отдельно на странице практики.

Начните с PDF. В базу знаний своего тенанта загружаются только FIN-01, COM-01 и CTRL-01. Затем в AI Studio откройте GigaBlocks и создайте нового агента.

Основной путь графа: **Ввод из чата → GigaChat Agent → Вывод в чат**. Добавьте **GigaRAG** из раздела **«Технологии Гига»** и **«Калькулятор»**; оба инструмента подключаются к входу **Tools** блока **GigaChat Agent**. В GigaRAG выберите свой тенант с документами.

Текст `system-prompt.txt` вставляется в системную инструкцию в параметрах блока GigaChat Agent. Запросы пользователя отправляются в чат собранного агента. Инструкцию и эталоны `queries-and-reference.md` в базу знаний не загружают; эталоны открывают для сверки после выполнения.

В журнале проверяют фактические вызовы поиска `gigarag_response_to_message` и калькулятора `evaluate_expression`, затем сверяют найденные сведения и вычисления с документами. Наличие блоков на схеме само по себе не подтверждает вызов инструментов.

Скачивание доступно без аккаунта GitHub. Для работы в AI Studio нужен собственный вход. Все данные вымышлены; оплаты и отправки в демонстрации нет.
